# GeroLAM

**A spatiotemporal transcriptomic map of subcutaneous adipose tissue aging in male mice**

## Interactive atlas

Explore spatial gene expression, volcano plots and UMAP in the [GeroLAM Shiny app](https://adlunglab.shinyapps.io/gerolam/).

The app is available as a research preview; publication is pending.
